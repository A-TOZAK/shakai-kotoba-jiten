# 社会ことば辞典 第3版

小学校3〜6年生の社会科の言葉389語を、やさしい意味・例文・関連語・見方考え方タグ・**図解**で調べられる静的サイトです（GitHub Pages）。

第3版（2026-07）で全面刷新しました。

- **389語すべてに自作SVG図解**（意味の文を読んでから図を見たら腑に落ちる、を合格ラインに設計）
- 教科書の紙面をお手本にしたフラットな画面（School Stockブランド）
- 五十音は「行」でしぼりこみ（濁音・半濁音は清音の行に含む）
- 子ども向け画面と「先生・おうちの方へ」を分離。フィードバックはGoogleフォームに一本化

## ファイル構成

```text
.
├── index.html
├── zukai-check.html        # 図解の検品一覧（全図解をグリッド表示）
├── assets/
│   ├── app.js
│   └── styles.css
├── data/
│   ├── terms.js            # 用語データ（389語）
│   └── zukai/
│       └── zukai_g3〜6.js  # 学年別の図解SVGデータ
└── scripts/
    ├── check_zukai.py      # 図解の機械検査（カバレッジ・構文・禁則・色・文字サイズ）
    └── build_zukai.py      # 1語1SVGファイル → zukai_g*.js への統合
```

## 用語の追加

`data/terms.js` の `termRows` に追加します。

```js
["unique-id", "消防署", "しょうぼうしょ", "し", 3, "火事からまちを守る", "安全", "意味", "例文", "関連語1|関連語2", "people-work|life-connection", "根拠"]
```

図解は1語1ファイルのSVG（viewBox="0 0 640 400"）を作り、`scripts/build_zukai.py` で統合します。作図の規準・禁則は `scripts/check_zukai.py` が機械検査します。

## 図解の方針

- 意味・例文から構図を自作する（教科書・地図帳の図表の引き写しはしない）
- 統計の数字は入れない（鮮度で腐るため）。地図の位置関係に嘘を描かない
- 国旗・人物の顔は描かない（不正確を避ける）
- 文字は22px以上・1枚7語まで・用語名は図中に書かない

## 意味・例文の根拠

学習指導要領、教科書、年間指導計画を参考に自作。
